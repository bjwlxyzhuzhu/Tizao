# 钛境智造

**钛合金构件智能制造与人机协同虚拟仿真实验**

面向宝鸡"中国钛谷"真实产业场景，构建钛合金构件从方案设计、真空熔炼、锻造、热处理、表面处理到人机协同工位评价的全流程虚拟仿真实验。学生通过 24 步交互完成工艺设计与验证，系统自动赋分并生成能力画像。

## 快速开始

环境要求：Node.js ≥ 22、pnpm ≥ 9。

```bash
pnpm install
pnpm dev
```

- 前端：http://localhost:5173
- 后端：http://localhost:8787/api/health

首次启动会自动创建数据库并写入演示账号：

| 账号 | 密码 | 角色 |
|---|---|---|
| student | student123 | 学生 |
| teacher | teacher123 | 教师 |
| admin | admin123 | 管理员 |

AI 层默认走规则引擎，不配置也能跑。需要接大模型时，复制 `.env.example` 为 `.env` 并填写 OpenAI 兼容接口：

```
AI_BASE_URL=https://api.deepseek.com/v1
AI_API_KEY=你的密钥
AI_MODEL=deepseek-chat
```

### 常用命令

| 命令 | 作用 |
|---|---|
| `pnpm dev` | 同时启动前端和后端 |
| `pnpm -r typecheck` | 全仓库类型检查 |
| `pnpm -r test` | 运行单元测试 |
| `pnpm --filter @tizao/sim-core test` | 只跑仿真内核测试 |
