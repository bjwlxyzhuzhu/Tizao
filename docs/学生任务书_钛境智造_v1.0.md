## 1. 项目是什么

做一个浏览器直接打开、不用装插件的虚拟仿真实验。

学生登录后，用 24 步完成：

```
方案设计 → 配料 → 真空熔炼 → 凝固判读 → 锻造 → 热处理 → 表面处理
        → 人机协同工位 → 优化 → 自动报告
```

每一步：输入参数 → 系统仿真 → 给出结果和分数 → 进入下一步。

**三个 3D 场景**：
1. VAR 真空自耗电弧炉熔炼
2. 锻压成形
3. 人机协同工位

**其余步骤**用表单、图表、AI 对话完成。**不是每一步都要 3D**——评审看的是实质交互，不是动画。

## 6. 可直接粘贴的 AI 提示词

### 6.1 给 Claude：架构与内核

```
你是 titan-sim 项目的架构与内核负责人。
仓库结构见 docs/开发说明。
任务：实现 packages/sim-core/src/thermal.ts 的一维瞬态热传导模型。
要求：
1. 纯函数，输入 VARParams，输出 TemperatureResult
2. 显式 FTCS，必须做稳定性检查 dt <= dx^2/(2α)
3. 单位：温度 °C，长度 mm，时间 s
4. 不新增依赖
5. 同时写 3 个单测：边界值、单调性、手算对比
先给实现，再给测试，最后给调用示例。
```

### 6.2 给 Codex：单文件实现

```
仓库：titan-sim
只修改这个文件：apps/web/src/components/steps/S07MeltParams.tsx
要求：
1. 使用 packages/shared 里的 submitStep 类型
2. 表单字段：电流(A)、电压(V)、熔速(mm/min)
3. 提交调用 api.submitStep('S07', payload)
4. 显示后端返回的 feedback
5. 不新增依赖，不修改其他文件
验收：pnpm lint && pnpm test
```

### 6.3 给 Codex：Blender 脚本

```
用 bpy 写一个脚本：assets/blender/var_furnace.py
生成真空自耗电弧炉的简化模型：
- 炉体：圆柱，直径 1200mm，高 3000mm
- 电极：圆柱，直径 200mm，长 1500mm，位于炉体上方
- 坩埚：圆柱，直径 800mm，高 1000mm，位于炉体内部底部
- 观察窗：炉体侧面 2 个圆形开口
导出到 assets/models/var_furnace.glb
要求：
- +Y 向上，单位米
- 应用全部变换
- 原点在底面中心
- 总面数 < 50000
- 材质用 Principled BSDF
脚本必须能直接运行：blender --background --python var_furnace.py
```

## 7. 代码规则（必须遵守）

### 7.1 必须做

- TypeScript `strict: true`
- 每个仿真函数必须是纯函数
- 每个模型至少 3 个单测
- 提交前跑 `pnpm lint && pnpm test`
- 密钥放 `.env`，`.env` 进 `.gitignore`

### 7.2 禁止做

| 禁止 | 原因 |
|---|---|
| 引入 UI 组件库 | 界面风格会失控 |
| 引入 ORM / 新状态库 / 新请求库 | 未经批准 |
| 用 `any` | 类型失去意义 |
| 修改 `packages/shared` 不通知对方 | 契约会崩 |
| 从网上下载来源不明的模型/贴图 | 软著和侵权风险 |
| 把企业数据发到公共大模型 API | 合规红线 |
| 把学生服务器当生产入口 | 等保红线 |
| 自己改业务规则（分值、判定条件） | 业务由教师定 |

### 7.3 提交信息格式

```
feat(sim-core): 添加 Avrami 相变模型
fix(web): 修复 S07 提交后不跳转
docs(readme): 补充启动说明
```

## 8. 验收标准

D7 当天按下面顺序走一遍，全过才算完成：

1. 打开网址，登录
2. 开始实验
3. 选择 TC4、P50 人体尺寸
4. AI 给出至少 2 条风险
5. 熔炼参数故意设错 → 温度曲线异常 → 出现反馈
6. 改正后继续
7. 锻压、工位各操作一次 → 画面有变化
8. 生成报告 → 有分数、有能力画像
9. 换一组参数重跑 → 分数不同、报告不同

**第 9 条是重点：如果两次结果一样，说明仿真没起作用。**
